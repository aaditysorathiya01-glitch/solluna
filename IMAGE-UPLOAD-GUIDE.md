# 📸 HOW TO ADD PRODUCT PHOTOS TO YOUR WEBSITE

## 🎯 **QUICK OVERVIEW:**
Your website code is now ready for images. You just need to:
1. Get product photos
2. Upload them to GitHub
3. Done! Images will show automatically

---

## 📁 **IMAGE FILE NAMES (EXACT NAMES REQUIRED):**

Save your product photos with these EXACT names:

1. `shots-fired.jpg` → SHOTS FIRED product
2. `who-party-v1.jpg` → WHO? Party V1
3. `who-party-v2.jpg` → WHO? Party V2
4. `who-girls-v1.jpg` → WHO? Girls Party V1
5. `who-girls-v2.jpg` → WHO? Girls Party V2
6. `who-couple-v2.jpg` → WHO? Couple V2

**Important:**
- File names must be EXACTLY as written above
- Use lowercase
- Use `.jpg` or `.png` (both work)
- If using PNG, change file names to `.png`

---

## 📸 **METHOD 1: Get Photos from Flipkart** (EASIEST)

### Step-by-Step:

1. **Open each Flipkart product link in browser**

2. **Save the main product image:**
   - Right-click on product image
   - Click **"Save image as..."**
   - Rename to correct name (see list above)
   - Save in a folder on your computer

3. **Repeat for all 6 products**

4. **You'll have 6 images ready!**

---

## 📤 **UPLOADING IMAGES TO GITHUB:**

### **STEP 1: Create Images Folder**

1. Go to your GitHub repository
2. Click **"Add file"** → **"Create new file"**
3. In the name field, type: `images/placeholder.txt`
4. Click **"Commit new file"**
5. ✅ Folder created!

### **STEP 2: Upload Images**

1. Click on **"images"** folder
2. Click **"Add file"** → **"Upload files"**
3. **Drag and drop** all 6 product photos
4. OR click **"choose your files"** and select them
5. Wait for upload to complete
6. Scroll down
7. Click **"Commit changes"**
8. ✅ Done!

### **STEP 3: Wait 2 Minutes**

- Your website will update automatically
- Visit your website to see images!

---

## 🖼️ **IMAGE QUALITY TIPS:**

### **Best Practices:**

✅ **Size:** 800px x 800px minimum  
✅ **Format:** JPG or PNG  
✅ **Background:** White or transparent  
✅ **Quality:** High resolution (not blurry)  
✅ **Angle:** Straight, centered product shot  

### **What to Avoid:**

❌ Low resolution/blurry images  
❌ Images with text overlay  
❌ Dark or unclear photos  
❌ Multiple products in one image

## 🔄 **UPDATE IMAGES LATER:**

To change/update images:

1. Go to GitHub repository
2. Click **"images"** folder
3. Click on image to replace
4. Click **trash icon** (delete)
5. Upload new image with SAME name
6. ✅ Updated!

---

## ⚠️ **TROUBLESHOOTING:**

### **Problem: Images not showing**

**Check:**
- Are file names EXACTLY correct?
- Are images in the "images" folder?
- Did you wait 2-5 minutes after upload?
- Try clearing browser cache (Ctrl + Shift + Delete)

### **Problem: Images look stretched/weird**

**Solution:**
- Use square images (same width and height)
- Recommended: 800px x 800px or 1000px x 1000px

### **Problem: Images too large (slow website)**

**Solution:**
- Compress images before upload
- Use: https://tinypng.com (free)
- Keep each image under 500KB
